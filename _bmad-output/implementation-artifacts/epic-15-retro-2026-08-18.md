# Epic 15 Retrospective — Medium-Priority Missing Auth Methods (Userpass, GitHub, Okta)

**Date:** 2026-08-18

**Stories:** 15.1, 15.2, 15.3

---

## Epic Summary

All three stories delivered 6 new CRDs (UserpassAuthEngineUser; GitHubAuthEngineConfig, TeamMap, UserMap; OktaAuthEngineConfig, Group) at 100% completion. Story 15.1 (Userpass) was the quality high-water mark: clean review, Kind lifecycle tests, `durationToSeconds()`, credential-defaulting that does not overwrite explicit keys. Story 15.2 (GitHub) followed the same TTL pattern but left the story file at `Status: review` with no Code Review Record. Story 15.3 (Okta) avoided the 14.2 credential-defaults bug, then reintroduced raw duration strings in `toMap()` — a pattern Epic 14 had already rejected.

This retrospective executed the prep work in-session (not as a follow-up list). TTL normalization, webhook philosophy, the AWS credential-defaults bug, story-file drift, and Epic 16 implementation notes are done.

## What Went Well

1. **100% delivery:** 3/3 stories done. 6 CRDs, docs, kustomize registration, main.go wiring.
2. **15.1 as the pattern to copy:** AppRole structure + AWS credential resolution + write-only password stripping + Kind install. Clean review (0 findings).
3. **14.2 credential-defaults lesson applied on new types:** Userpass and Okta defaulters set `PasswordKey` only when empty.
4. **GitHub `toMap()` correctness:** Conditional inclusion, `durationToSeconds()`, Team/User maps emit only `{"value": policies}` so Vault's extra `key` field is filtered.
5. **No shared-framework changes:** All work additive. CRD registration checklist followed.
6. **Integration-test classification honored:** Userpass = Install in Kind; GitHub/Okta = Skip (cloud).

## What Could Be Improved

1. **TTL pattern split inside the epic:** 15.1 and 15.2 used `durationToSeconds()`. 15.3 Okta emitted raw strings and deferred the finding as "pre-existing." That is how a known defect becomes a new type.
2. **Phase B story-file finalization still drifting:** 15.2 `Status: review` in the story file vs `done` in sprint-status. Fourth epic with this class of gap. `.cursor` create-story template was also corrupted (git commit text instead of markdown).
3. **Review findings recorded but not fixed (15.3):** The TTL defer was the same class of issue Epic 14 already actioned. Deferring it onto "older types" let it land in a new type.
4. **Epic 14 prep items were not executed last retro:** Three of four open items sat until this session. Mandate for this retro: do the work before closing.
